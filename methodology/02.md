# 02 · AI 能力预验证

> 节点挂载文件,不占固定顺序。回答:这个 AI 节点在真实输入上够不够格?防的是"演示惊艳,上线拉胯"。

---

## 一、挂载规则(全文件最重要的一条)

> **任何时刻,只要一个 AI 节点进入方案——判定时、选型时、评审中老板临时提出——该节点自动带上`待验证`状态,并生成预验证任务包。结果表不回收,该节点不得进入阶段 5 的 AI 能力规格。**

验证可以晚做,不能不做就写规格。它不阻塞出原型(快车道照常 mock 演示),只阻塞"没验证就开工"。

---

## 二、分工:本套件只出题和验收,不跑验证

| 环节 | 谁做 | 在哪做 |
|---|---|---|
| 出题(生成任务包) | 本套件 | 本会话 |
| 跑验证 | 使用者或算法同学 | **新开的干净 session** |
| 回收登记 | 本套件 | 本会话 |

为什么必须拆出去:在讨论过需求的会话里跑验证,模型带着"什么答案是你想要的"的全部上下文,测出来的是表演不是能力。干净 session 里模型只拿到和线上一样的输入,结果才可信。附带好处:不塞爆本会话上下文;任务包本身就是给算法同学的标准实验委托书。

---

## 三、预验证任务包模板

`需求-[[需求名]]/AI能力预验证任务包.md`

```markdown
# [[需求名]] · AI 能力预验证任务包(节点:[[AI-XX]])

## 1. 能力定义
- 输入:[[ 如:用户手机拍摄的化验单照片 ]]
- 期望输出:[[ 如:血糖 / 血脂四项的数值与单位 ]]
- 一句话:这个节点到底要 AI 干什么。

## 2. 样例采集要求(样例必须真实,由使用者提供,AI 不得代编)
| 类型 | 数量 | 说明 |
|---|---|---|
| 正常样例 | ~50% | 真实但清晰的输入 |
| 脏样例 | ~30% | 真实世界的样子:拍歪、反光、手写混排、多页拼一张 |
| 非目标物 | ~20% | 根本不是目标物的输入,考察会不会硬答 |

建议总量 15-20 个。少于 10 个的结论只能标`初步`。

## 3. 判定标准(先锁定,再跑;跑完再定标准视为无效)
- 通过:[[ 如:四项数值与单位全部正确 ]]
- 可接受:[[ 如:漏提但明确提示用户手动输入 ]]
- 危险失败:[[ 如:编造数值——照片是 6.2 输出 5.8 ]]

## 4. 危险红线
[[ 高风险需求必填。哪类失败一票否决,如:健康数值不允许任何编造 ]]

## 5. 结果表模板(跑完带回)
| 样例 | 输入特征 | 期望 | 实际 | 判定(过/可接受/危险) |
|---|---|---|---|---|

汇总:通过 X / 总数 N;可接受 Y;危险失败 Z。
所用 prompt 全文附后(将作为实测基线移交)。
```

## 四、回收登记

结果表带回后,本套件做四件事:

1. 登记通过率与危险失败数,写入判定卡的 AI 节点清单。
2. 节点状态翻转,三种结论:

| 结论 | 条件(参考) | 后续 |
|---|---|---|
| `已验证达标` | 通过率达预期且危险失败为 0 | 按原方案进阶段 3/5 |
| `需人工兜底` | 能力可用但存在危险失败或不稳定 | 方案必须加人工确认环节,写进主线卡 AI/规则/人工边界 |
| `已降级` | 通过率不可接受 | 该节点降为规则或人工方案,回阶段 3 改方案 |

3. 样例集归档进 `[[产品名]]/评测集/`,作为阶段 5 评测集的种子。
4. 实测基线 prompt 连同通过率一并归档,构建交接时作为"实测基线(X/N)"移交,防止工程从零重造。

> 高风险需求:危险失败 > 0 时,`已验证达标`不可选,只能`需人工兜底`或`已降级`。

---

## 五、硬闸

- [ ] 判定标准在跑之前已锁定。
- [ ] 样例是真实的、含脏样例和非目标物,不是理想样例。
- [ ] 验证在干净 session 或算法侧执行,不在本会话跑。
- [ ] 结果表未回收的节点,状态停在`待验证`,阶段 5 不放行。
- [ ] 高风险 + 危险失败 > 0 → 强制人工兜底或降级。
- [ ] 样例与基线 prompt 已归档评测集。

---

## 六、常见错误

| 错误 | 修正 |
|---|---|
| 用理想样例验证 | 重开任务包,按 2 节比例补脏样例 |
| 跑完再补判定标准 | 结果作废,锁标准重跑 |
| 在需求会话里直接跑 | 结果标`已污染`,新 session 重跑 |
| mock 演示效果被当成验证结论 | mock 只证明流程通,能力结论只认结果表 |
| 危险失败被平均进通过率 | 危险失败单列,高风险场景一票否决 |
